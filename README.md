# Desafio Processo Seletivo Visão Jr.

Projeto desenvolvido para a Fase 3 do processo seletivo da **Visão Jr.**, empresa júnior da **Universidade Federal de Ouro Preto**, com o objetivo de demonstrar a utilização de um fluxo de versionamento e colaboração utilizando Git e GitHub.

## Sobre o projeto

O projeto consiste na criação de uma página web simples, desenvolvida com **HTML e CSS**, utilizando um fluxo de trabalho baseado em branches, commits e Pull Requests.

## Estrutura do projeto

```text
.
├── index.html
├── style.css
└── imagens/
    ├── logo-comunicar.png
    └── background.png
```

## Tarefas

* **TASK-01 — Criação da Página Principal**

  * Estrutura básica da página;
  * Background;
  * Conteúdo principal;
  * Botão de ação.

* **TASK-02 — Implementação do Header**

  * Header da página;
  * Logo da empresa;
  * Logo configurada como link para a página inicial.

* **TASK-03 — Implementação do Footer**

  * Footer da página;
  * Estilização própria;
  * Informações de direitos autorais.

## Fluxo de desenvolvimento

O desenvolvimento foi realizado seguindo o fluxo proposto no desafio:

```text
main
  │
  └── dev
       │
       ├── task/criacao-pagina-principal
       ├── task/header
       └── task/footer
```

Cada tarefa foi desenvolvida em sua própria branch e posteriormente integrada à branch `dev` por meio de Pull Requests. Ao final, a branch `dev` foi integrada à `main`.

## Tecnologias utilizadas

* HTML5
* CSS3
* Git
* GitHub
